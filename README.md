## 📖 About MEPT

**MEPT (Maritime English Proficiency Test)** သည် ရေကြောင်းလောကသို့ ဝင်ရောက်မည့် ကုန်းပတ်အရာရှိများ၊ စက်မှုအရာရှိများနှင့် သင်္ဘောသားများ၏ ရေကြောင်းသုံး အင်္ဂလိပ်စာ အရည်အချင်းကို စစ်ဆေးရန် ဖန်တီးထားသော **Progressive Web Application (PWA)** ဖြစ်ပါသည်။

### ✨ Features

| Feature | Description |
|---------|-------------|
| 📖 **Grammar & Vocabulary** | B1/B2 Level Multiple Choice Questions |
| 📰 **Reading Comprehension** | True/False/Doesn't Say Passages |
| 🎧 **Listening Skills** | Audio-based Multiple Choice |
| ✍️ **Writing Tasks** | Short Message & Paragraph Writing |
| 🗣️ **Speaking Test** | Interactive Questions with AI Auto-Grading |
| 📊 **Auto Grading** | Instant Results with Keyword Matching |
| 📥 **PDF Download** | Download Exam Results as PDF |
| 📱 **PWA Support** | Install on Mobile & Desktop |
| 🔐 **Subscription System** | Start Date - Expire Date Control |
| 🌐 **Offline Support** | Works without Internet (Cached) |
